# Password Validator

Pequeño proyecto realizado para practicar Python.

## Características

- Comprueba si la contraseña está vacía.
- Comprueba la longitud mínima.
- Comprueba si contiene números.
- Comprueba si contiene letras.
- Comprueba si contiene mayúsculas.
- Comprueba si contiene minúsculas.

## Tecnologías

- Python 3
